# Logo PREN Team 03

**Idee:** Ein Knochen im Erkennungsrahmen – der Moment, in dem unser
Roboter-Hund den Knochen findet.

| Datei                                | Verwendung                                             |
|--------------------------------------|--------------------------------------------------------|
| `pren-logo-horizontal.svg` / `.png`  | Standard: Titelseiten, Folien, README                  |
| `pren-logo-stacked.svg`              | Wenn wenig Breite zur Verfügung steht                  |
| `pren-logo-symbol.svg` / `.png`      | Nur das Zeichen, z. B. Avatar, Aufkleber am Roboter    |
| `pren-logo-symbol-small.svg`         | Vereinfachtes Zeichen für sehr kleine Grössen (< 32 px) |
| `pren-logo-favicon.svg`              | Browser-Tab                                            |
| `pren-logo-app-icon.svg`             | Weisses Zeichen auf schwarzer Kachel                   |
| `*-white.svg`                        | Auf dunklem Hintergrund                                |

## Regeln

- **Farbe:** nur Schwarz `#000000` oder Weiss `#FFFFFF` – keine anderen Farben, Verläufe oder Schatten.
- **Schrift:** Space Grotesk (Bold für «PREN», Medium für «Team 03»), als Pfade im SVG enthalten. Lizenz: SIL Open Font License.
- **Schutzzone:** rundherum mindestens die Breite eines Rahmenwinkels (ca. ¼ der Symbolhöhe) freihalten.
- **Mindestgrösse:** Lockup 120 px bzw. 25 mm breit; Symbol 24 px, darunter `pren-logo-symbol-small.svg` verwenden.
- **Nicht:** verzerren, drehen, Elemente verschieben, Schrift ersetzen, auf unruhige Hintergründe setzen.
